CONTROL DE TERAPIAS - VERSION COMPLETA INDEPENDIENTE

Esta versión conserva la idea y las funciones principales de tu diseño original,
pero ya NO depende de window.dataSdk ni de los SDK internos de Canva.

Incluye:
- Hoy y próxima cita
- Calendario día/semana/mes
- Pacientes
- Control de sesiones
- Pagos por día/semana/mes
- Tarifas Particular e IPS
- Datos locales en el dispositivo
- Exportación e importación de respaldo JSON
- Manifest y Service Worker para PWA

IMPORTANTE:
La versión todavía usa Google Fonts cuando hay internet; la información se
guarda localmente. Para datos reales de pacientes conviene añadir seguridad,
cifrado y una política de respaldo antes de usarla profesionalmente.
